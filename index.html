1. Pengaruh Nilai a a > 0

Karena a > 0, parabola terbuka ke atas dan memiliki titik balik minimum.

2. Pengaruh Nilai b & Sumbu Simetri x = 0

Karena b = 0, sumbu simetri berimpit dengan sumbu Y (x = 0).

3. Pengaruh Nilai c (0, 0)

Grafik memotong sumbu Y di titik (0, 0).

4. Titik Puncak (Vertex) (0, 0)

Koordinat titik puncak berada di (0, 0) dengan nilai minimum y = 0.

5. Diskriminan (D = b² - 4ac) D = 0

Karena D = 0, parabola menyinggung sumbu X tepat di satu titik: (0, 0).

📚 Ringkasan Materi: Karakteristik Fungsi Kuadrat

Bentuk umum fungsi kuadrat adalah f(x) = ax² + bx + c dengan syarat a ≠ 0. Setiap parameter memiliki peran unik dalam membentuk kurva parabola:

a

Peran Koefisien a

  • a > 0 (Positif): Parabola terbuka ke atas (seperti mangkuk / senyum 😊). Puncaknya adalah titik minimum.
  • a < 0 (Negatif): Parabola terbuka ke bawah (seperti bukit / cemberut ☹️). Puncaknya adalah titik maksimum.
  • Kelengkungan: Semakin besar nilai mutlak |a|, kurva semakin sempit/runcing. Semakin kecil |a| (mendekati 0), kurva semakin lebar/landai.
b

Peran Koefisien b

  • Menentukan posisi sumbu simetri (x = -b / 2a) dan letak titik puncak terhadap sumbu Y.
  • a dan b bertanda sama (keduanya + atau keduanya -): Titik puncak berada di sebelah kiri sumbu Y.
  • a dan b berlawanan tanda: Titik puncak berada di sebelah kanan sumbu Y.
  • b = 0: Titik puncak berada tepat pada sumbu Y.
c

Peran Konstanta c

  • Menunjukkan titik potong parabola dengan sumbu Y, yaitu pada koordinat (0, c).
  • c > 0: Memotong sumbu Y di atas titik asal (positif).
  • c = 0: Kurva melewati titik pusat koordinat (0, 0).
  • c < 0: Memotong sumbu Y di bawah titik asal (negatif).

📐 Diskriminan (D = b² - 4ac) & Hubungannya dengan Sumbu X

D > 0 Grafik memotong sumbu X di 2 titik berbeda (memiliki 2 akar real berbeda).
D = 0 Grafik menyinggung sumbu X di 1 titik (memiliki 2 akar real kembar).
D < 0 Grafik tidak memotong sumbu X (melayang di atas atau di bawah sumbu X).
